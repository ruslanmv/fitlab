fits

Deterministic VRAM math

weights (params × bits⁄8) + KV cache (2·layers·kv_heads·head_dim·ctx·2 B) + 0.9 GB runtime. fits ≤ 92 % · tight ≤ 100 % · offload ≤ 160 % (partial GPU). Recomputed live for the rig you pick.

runs

Real weekly benchmarks

One model per week on real hardware: load time, TTFT, median tok/s over 3 seeded runs, peak VRAM. CI runs Kaggle's free T4; the community adds 3060s, 4070s and Macs via the notebook.
