What the FitLab score means

This is a deployment-readiness score, not an intelligence benchmark. It combines hardware fit, model-capability proxy, Hugging Face momentum, speed, and current stack compatibility.

Evaluation coverage

FitLab currently evaluates deployment behavior and software compatibility. It does not yet publish task-quality scores such as coding pass rate, MMLU-style accuracy, hallucination rate, or long-context retrieval accuracy. The UI keeps that gap visible instead of presenting estimated runtime data as model quality.
